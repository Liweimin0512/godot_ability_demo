# GDScript 演示测试

在包含 `project.godot` 的演示目录运行。首次检出时先导入资源。把 `godot` 换成本机 Godot 4.6 的可执行文件路径，在 Windows 上可以用 console 版读取日志和退出码。

```sh
godot --headless --path . --editor --import
godot --headless --path . res://tests/test_runner.tscn -- all
```

最后一个参数可换成 `unit`、`integration` 或 `attributes`。省略时运行全部。成功会输出 `PASS Godot demo tests` 并返回 0。断言失败或测试超时返回 1，参数错误返回 2。自动化执行时同时检查成功标记和退出码。

- 单元测试覆盖鼠标按键映射、黑板通知与实例隔离、状态到期与刷新、周期计时隔离、低血量扣至零，以及技能消耗余额不足时保持原值。
- 属性测试覆盖修饰器顺序和上下限、单独移除与按来源清理、等级曲线与衍生加成的组合、属性集重新初始化和玩家实例隔离，以及生命上限变化时的单次通知和法力回复。
- 集成测试加载主场景，通过背包装备大剑和天赋系统取得三连击，再把合成的鼠标右键事件交给角色的未处理输入回调。敌人在真实碰撞范围外时，第三段应挥空。把敌人放入范围后，第三段应附加一次流血，随后扣血三次，每次 3 点，到期后停止。
- 释放回归使用弱引用检查天赋替换后的旧技能、卸载场景时仍在施放的技能及其行为树和黑板，以及提前移除玩家时仍在等待的启动计时器。加上 `--verbose` 可以同时查看 Godot 的退出诊断。

集成用例绕过 HUD 对鼠标的拦截，直接测试玩法输入、物理选敌和状态结算。要带窗口运行同一套测试，可以去掉 `--headless`。
