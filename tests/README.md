# GDScript 演示测试

在包含 `project.godot` 的演示目录运行。首次检出时先导入资源。把 `godot` 换成本机 Godot 4.6 的可执行文件路径，在 Windows 上可以用 console 版读取日志和退出码。

```sh
godot --headless --path . --editor --import
godot --headless --path . res://tests/test_runner.tscn -- all
```

最后一个参数可换成 `unit` 或 `integration`。省略时运行全部。成功会输出 `PASS Godot demo tests` 并返回 0。断言失败或测试超时返回 1，参数错误返回 2。自动化执行时同时检查成功标记和退出码。

- 单元测试覆盖鼠标按键映射、黑板通知与实例隔离、行为树等待使用帧时间、状态到期与刷新、周期计时隔离、低血量扣至零，以及技能消耗余额不足时保持原值。
- 集成测试加载主场景，通过背包装备大剑和天赋系统取得三连击，再将合成右键送进视口的正常输入链路。三段挥空时没有伤害和流血。入范围后逐段扣一次血，整套结束才开始冷却，第三段附加一次流血，随后扣血三次，每次 3 点，到期后停止。
- 释放回归使用弱引用检查天赋替换后的旧技能、卸载场景时仍在施放的技能及其行为树和黑板，以及提前移除玩家时仍在等待的启动计时器。加上 `--verbose` 可以同时查看 Godot 的退出诊断。

要带窗口运行同一套测试，可以去掉 `--headless`。无界面运行时可加 `--fixed-fps 60`，确认计时在固定帧步进下也一致。
